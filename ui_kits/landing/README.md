# UI Kit · Landing (sitio de marca)

Recreación del sitio de Estudio Cimiento, construido sobre las fundaciones de marca (no hay codebase previo: el brief de marca es la fuente de verdad).

## Pantalla
- `index.html` — landing completa: nav, hero, proceso, caso y wedge.

## Secciones
- `Nav.jsx` — header sticky con logo y CTA.
- `Hero.jsx` — promesa principal + símbolo sobre grilla arquitectónica.
- `Process.jsx` — las cuatro fases sobre superficie tinta (usa `PhaseList`).
- `Proof.jsx` — caso Gryphon en formato contexto · problema · solución · resultado. Métricas exactas marcadas como "a confirmar" hasta validarlas.
- `Wedge.jsx` — oferta de entrada + cierre + footer.

## Notas
- Voz de marca: minúscula como tratamiento, sin jerga, sin guiones largos, sin frases de contraste.
- El acento metálico vive solo en detalle (símbolo, hairline, CTA primario).
